# Sneaker Store Web Application

A modern and responsive sneaker e-commerce project built as a student web application.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS** (Styling & Responsive Design)
- **JavaScript** (DOM Manipulation & Interactive Cart)

## ✨ Key Features
- Dynamic Sneaker Catalog Display
- Interactive Shopping Cart powered by `localStorage`
- Fully responsive navigation and product layout

## 🚀 How to Run
Open `index.html` directly in any web browser.
